Quick Start

How to link the stylesheet

Two files ship together. Keep cit-styles.css and your HTML in the same folder, then add the three lines below to <head>. That's all that's needed.
What goes in <head>

1. Google Fonts link — loads Lato, Noto Serif, and Outfit.

2. The CIT stylesheet itself.

3. data-theme="light" on the <html> tag activates the light palette. Change to "dark" for dark mode.

HTML — <head>
<!-- ① Google Fonts -->
<link href="https://fonts.googleapis.com/css2?
  family=Lato:ital,wght@0,400;0,700;1,400;1,700
  &family=Noto+Serif:ital,wght@0,400;0,700;1,400;1,700
  &family=Outfit:wght@400;600;700
  &display=swap"
      rel="stylesheet"/>

<!-- ② CIT stylesheet -->
<link rel="stylesheet"
      href="cit-styles.css"/>

Rebranding example

Override any single variable — or all of them — to change the whole site's color scheme without touching the HTML.

--accent --nav-grad --hero-bg --footer-bg
CSS — custom rebrand
/* swap entire palette to green/teal */
:root {
  --accent:    #0f7a5a;
  --nav-grad:  linear-gradient(
    135deg, #063d2c, #0f7a5a
  );
  --hero-bg:   linear-gradient(
    180deg, #d0e8e0, #edf7f3
  );
}

/* or theme just one section */
#special-section {
  --section-bg: #fff8e8;
  --card-border: #c8a830;
}

<!-- JS for tab switching -->
<script>
function switchPage(i) {
  document.querySelectorAll('.nav-tab')
    .forEach((t,idx) =>
      t.classList.toggle('active',idx===i));
  document.querySelectorAll('.page-section')
    .forEach((p,idx) =>
      p.classList.toggle('active',idx===i));
}
</script>

Tabbed Page Sections

Each .page-section maps to a nav tab by index. Only the one with .active is shown. switchPage(N) toggles both.

Tab 0 → id="page-0"
Tab 1 → id="page-1"
Tab N → id="page-N"
HTML
<div id="site-content">

  <section class="page-section active"
            id="page-0">
    <!-- home page content -->
  </section>

  <section class="page-section"
            id="page-1">
    <!-- about page content -->
  </section>

</div>

<!-- nav tabs must match -->
<span class="nav-tab active"
      onclick="switchPage(0)">Home</span>
<span class="nav-tab"
      onclick="switchPage(1)">About</span>

Fonts & Text

Typography

Three fonts, one link. Outfit, Lato, and Noto Serif are all loaded from Google Fonts via the single <link> tag. The CSS references them by name — if the link is missing they fall back to sans-serif or serif.
Outfit — Heading Font
hero-title (68px) Heading
section-heading (42px) Section Title
card-title (22px) Card Label
CSS
/* apply Outfit anywhere */
.my-heading {
  font-family: var(--font-heading);
  font-weight: 700;
  /* no true italic — omit font-style */
}

/* fluid scaling with clamp() */
.hero-title {
  font-size: clamp(
    38px, 5.5vw, 68px
  );
}

Required JS — works for all three options

One function handles everything. List all the icon element IDs you used so they all update together.

Using multiple toggles at once? Give each a unique id and add all of them to the icons array.
JS — put in <script> before </body>
let isDark = false;

function toggleDark() {
  isDark = !isDark;

  document.documentElement
    .setAttribute(
      'data-theme',
      isDark ? 'dark' : 'light'
    );

  // update all toggle icons
  ['dm-icon', 'dm-float']
    .forEach(id => {
      const el = document.getElementById(id);
      if (el) el.textContent =
        isDark ? '🌙' : '☀️';
    });
}

// to start in dark mode:
// set isDark = true above and
// change data-theme="dark" on html
